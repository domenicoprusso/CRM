# Bitcall - CRM

## Progetto
CRM interno Bitcall per gestione clienti, lead, opportunità commerciali e pipeline di vendita.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Repository
- GitHub: https://github.com/domenicoprusso/CRM.git
- Branch principale: `main`

## Comandi
```bash
npm install
npm run dev      # sviluppo locale
npm run build    # build produzione
```

## Note
- `node_modules/` non inclusa — eseguire `npm install` dopo clone/spostamento
